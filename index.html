Knurl

Diagnóstico e instalação de pacotes TeX para macOS. Arraste seu projeto .tex, descubra o que falta, instale com um clique.

macOS 15+ Apple Silicon Grátis & open source
⬇ Baixar Knurl Código-fonte

v1.0 · ~3 MB · build arm64

O que ele faz

Do erro de compilação ao pacote instalado, sem sair do app.

📄

Análise de projetos .tex

Arraste a pasta ou o arquivo principal: o Knurl mapeia classes, pacotes (\usepackage) e engines usados.

🔍

Diagnóstico do ambiente

Detecta distribuição (TeX Live, BasicTeX, Tectonic), engines ativos e o que está quebrado ou ausente.

🗺️

Mapa CTAN → TL

Nomes de pacote do CTAN traduzidos para os nomes reais no TeX Live — overrides embutidos + mapa oficial do TUG.

📦

Instalação com um clique

Instala os pacotes faltantes via tlmgr, pedindo privilégio de admin só quando necessário.

📊

Relatório exportável

Gera relatório completo em JSON ou Markdown — ambiente, pacotes e ações realizadas.

✨

UI nativa em glass

Janela translúcida, sidebar flutuante e tiles de status — feita para Sequoia, clara e escura.

Como instalar

Menos de um minuto.

  1. Baixe o KnurlClique em “Baixar Knurl” e descompacte o Knurl.zip.
  2. Mova para AplicativosArraste Knurl.app para a pasta /Applications.
  3. Abra na primeira vezBotão direito no app → Abrir. É só na primeira abertura.
  4. Arraste seu projetoSolte uma pasta .tex na janela e siga o diagnóstico.
⚠️ O build é assinado com uma conta Apple gratuita e não passa por notarização da Apple. No seu Mac ele abre normal; em outros Macs, use botão direito → Abrir na primeira vez (ou xattr -dr com.apple.quarantine Knurl.app).
